מה זה Git?

Git היא מערכת לניהול גרסאות — היא עוקבת אחרי כל שינוי בקוד ומאפשרת לנו לחזור לכל נקודה בזמן, לעבוד במקביל ולמזג שינויים בבטחה.

כל שינוי עובר שלוש תחנות במחשב שלנו, ומשם לעותק בענן. נכיר אותן בהמשך.

$ git log --oneline
a41f9c2add login pageHEAD
7be20d1fix header on mobile
3c8e6faadd contact form
0d5a1b7first commit

כל שורה היא נקודה בזמן שאפשר לחזור אליה

המילים של Git

1 repo

Repository

the project + its history

תיקיית הפרויקט ש-Git עוקבת אחריה, יחד עם כל ההיסטוריה שלה.

2 commit

Commit

a saved snapshot

תמונת מצב שמורה עם הודעה. לכל commit יש מזהה קצר, כמו a41f9c2.

3 head

HEAD

you are here

הסימון "אנחנו כאן": ה-commit שעליו אנחנו עומדים עכשיו.

4 remote

Remote

a copy somewhere else

עותק של ה-repository במקום אחר, בדרך כלל GitHub. אצלנו קוראים לו origin.

פקודות ליבה

1 clone

clone

מורידים עותק מלא של repository מ-GitHub למחשב — כולל כל ההיסטוריה. עושים את זה פעם אחת.

2 add

add

מסמנים אילו קבצים לכלול ב-commit הבא — רק מה שנסמן יישמר.

3 commit

commit

שומרים snapshot של השינויים עם הודעה תיאורית — כל commit הוא נקודת חזרה.

4 push / pull

push / pull

push שולח commits ל-GitHub. pull מביא אלינו רק את מה שהשתנה מאז, בכל פעם מחדש.

משכפלים repository

1 copy url

מעתיקים את ה-URL

ב-GitHub נכנסים לדף הפרויקט, לוחצים Code → HTTPS ומעתיקים את הכתובת.

GitHub · Code · HTTPS · Copy URL
2 clone

משכפלים

מריצים את הפקודה בטרמינל — Git יוצר תיקייה עם כל הקוד וההיסטוריה.

>_ git clone https://github.com/user/repo.git
3 enter

נכנסים לתיקייה

Git יצרה תיקייה בשם הפרויקט. נכנסים אליה בטרמינל, או פותחים אותה ישר בעורך הקוד: File → Open Folder.

>_ cd repo-name && ls

שומרים שינויים

1 status

בודקים מצב

רואים אילו קבצים השתנו — קבצים אדומים עדיין לא סומנו, ירוקים מוכנים ל-commit.

>_ git status
2 add

מסמנים קבצים

מוסיפים ל-Staging Area — add . אומר ״הכל״, אפשר גם לציין קובץ ספציפי.

>_ git add .
3 commit

שומרים snapshot

יוצרים commit עם הודעה תיאורית קצרה — מה השתנה ולמה. זה יישמר בהיסטוריה.

>_ git commit -m "add login page"

מסנכרנים עם GitHub

1 push

שולחים ל-GitHub

שולחים את ה-commits שלנו ל-GitHub — מעדכנים את הענן עם הגרסה העדכנית שלנו.

>_ git push
2 pull

מושכים מ-GitHub

מביאים שינויים חדשים מ-GitHub — מישהו אחר דחף קוד, או ששינינו משהו ממחשב אחר.

>_ git pull
3 log

רואים היסטוריה

מציגים רשימה קצרה של ה-commits האחרונים — מי שינה מה ומתי.

>_ git log --oneline

מה לא נכנס ל-Git

הקובץ .gitignore הוא רשימה של מה ש-Git מתעלם ממנו: סודות, תלויות שאפשר להתקין מחדש וקבצים שנוצרים אוטומטית.

מפתח שעלה ל-GitHub נחשב חשוף. גם אם נמחק אותו, הוא נשאר בהיסטוריה, אז נחליף אותו במפתח חדש.
# .gitignore
.envsecrets
node_modules/dependencies
dist/build output
*.loglogs

קובץ שכבר נמצא במעקב לא יושפע מ-.gitignore
