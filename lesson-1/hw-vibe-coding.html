3 open PR

פותחים Pull Request

Pull Request היא בקשה לאחד את ה-branch שלנו ל-main. נכנסים ל-repository ב-GitHub, לוחצים על Compare & pull request, כותבים מה שינינו, ולוחצים Create pull request.

feature/dark-mode had recent pushesCompare & pull request
Add dark mode toggle
מה השתנה: כפתור למצב כהה
איך בודקים: לוחצים על הכפתור, והצבעים מתחלפים
Create pull request
למה ה-dark mode עוד לא ב-Lovable? Lovable מתעדכן רק מ-main, והשינוי שלנו נמצא כרגע ב-branch נפרד. הוא יגיע ל-Lovable אחרי ה-merge, בשקף הבא.

Merge pull request → Confirm merge → Delete branch

חוזרים ל-main

מבקשים מ-Claude Code לעבור ל-main ולמשוך את השינויים, כך שהפרויקט על המחשב שלנו יכלול את ה-merge. ב-Lovable השינוי מופיע לבד, ונלחץ Publish changes כדי לעדכן את האתר החי.

› Switch to main and pull the latest changes from GitHub
