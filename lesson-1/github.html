מה זה GitHub?

GitHub היא פלטפורמת ענן לאחסון ושיתוף קוד. היא לא Git — היא הבית שבו הפרויקטים שלנו חיים ברשת ומאפשרת לצוות לעבוד יחד על אותו קוד.

מה שנדחוף עם push — נשמר בענן וזמין לכל הצוות.

Git מול GitHub

Git

כלי שמותקן על המחשב שלנו
  • מה הוא עושה: עוקב אחרי שינויים ושומר היסטוריה
  • איפה הוא רץ: מקומית, גם בלי אינטרנט
  • איך עובדים איתו: פקודות כמו add ו-commit

GitHub

שירות בענן לאחסון repositories
  • מה הוא עושה: מאחסן קוד ומחבר בין אנשים
  • איפה הוא רץ: באתר, דרך הדפדפן
  • איך עובדים איתו: Pull Requests, code review וניהול משימות

הגשר ביניהם: git push ו-git pull

מושגי ליבה

1 repo

Repository

כל הקבצים, ההיסטוריה וה-commits של הפרויקט — בתיקייה אחת, עם עותק ב-GitHub.

2 branch

Branch

קו עבודה נפרד באותו פרויקט. עובדים עליו בנפרד מ-main, בלי לשבור את מה שעובד.

3 fork

Fork

עותק של פרויקט של מישהו אחר, בחשבון שלנו — כדי לשנות בלי לגעת במקור.

4 PR

Pull Request

בקשה להכניס את השינויים שלנו ל-main, אחרי שהצוות בדק אותם ב-code review.

מה זה Branch?

Branch הוא קו עבודה נפרד באותו פרויקט. נעבוד עליו בחופשיות, ו-main — ה-branch הראשי עם הגרסה שעובדת — לא ישתנה עד שנחליט לאחד.

כמו טיוטה של מסמך: כותבים בה מה שרוצים, והמסמך המקורי נשאר נקי עד שמעבירים אליו את מה שעבד.
  • branch לכל פיצ'ר או תיקון, וכמה במקביל
  • branch חדש נוצר מתוך branch קיים, כמו עותק שלו, אבל בלי לשכפל את הקבצים
  • ניצור ונעבור אליו עם git switch -c name

מה זה Fork?

Fork הוא עותק של repository של מישהו אחר, שנשמר בחשבון GitHub שלנו. נוכל לשנות בו הכל, והמקור לא יושפע.

כמו להעתיק מתכון מהמחברת של חבר למחברת שלנו: משנים בחופשיות, ואם יצא שיפור — מציעים אותו לחבר.
  • נשתמש בו כשאין לנו הרשאה לכתוב בפרויקט המקורי
  • השיפור חוזר למקור דרך Pull Request
  • בתוך הצוות שלנו בדרך כלל מספיק Branch

Clone, Fork או Branch?

שאלה אחת מבדילה ביניהם: איפה נוצר העותק?

Clone

copy to our computer
מה מקבלים: עותק של ה-repository במחשב שלנו.
מתי: כשנרצה לעבוד על הקוד מקומית.

Branch

line of work in the same repo
מה מקבלים: קו עבודה נפרד באותו repository.
מתי: כשיש לנו הרשאה ונעבוד על שינוי חדש.

Fork

copy to our account
מה מקבלים: עותק של ה-repository בחשבון GitHub שלנו.
מתי: כשנרצה לתרום לפרויקט שאין לנו הרשאת כתיבה אליו.
