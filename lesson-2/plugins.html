איפה אנחנו?

כתבנו Skills למשימות שלנו. עכשיו נארוז אותם, כדי שגם אחרים יוכלו להשתמש בהם.

Skills

Plugin

כמה Skills בחבילה אחת, שקל להעביר לאחרים.

Agents

עובדים שמקבלים משימה, משתמשים בהוראות וחוזרים עם תוצאה.

ראש צוות

סוכן שמחלק את העבודה בין סוכנים אחרים.

MCP

חיבור לכלים: לפתוח טיקט ב-Jira, לקרוא דף מ-Notion.

ספר מתכונים שלם, במקום דפים בודדים. בהמשך נוכל לארוז באותה חבילה גם את הסוכנים שלנו.

שלוש מילים

לפני שמתקינים משהו, נסדר את המושגים.

Skill

one task

הוראות למשימה אחת, בקובץ SKILL.md. כאלה כבר כתבנו.

כמו: מתכון אחד.

Plugin

a package

חבילה של כמה Skills. לפעמים יש בה גם סוכנים, חיבורי MCP ו-hooks (כללים שרצים לבד). מתקינים את כולה בבת אחת.

כמו: ספר מתכונים.

Marketplace

a catalog

חנות: repository ב-GitHub שיש בו רשימת Plugins. מוסיפים אותה פעם אחת, ומתקינים ממנה מה שרוצים.

כמו: מדף בחנות ספרים.

מה פעיל ב-Claude Code?

    "superpowers@claude-plugins-official": true,
    "frontend-design@claude-plugins-official": true
  }
}

Claude Code או הצ׳אט?

ב-Claude Desktop יש שתי לשוניות: הצ׳אט, ו-Code שבה רץ Claude Code. לכל אחת מהן רשימת Plugins נפרדת.

Claude Code

terminal · VS Code · Code tab

ה-Plugin נשמר במחשב שלנו. אפשר להתקין אותו בשלוש דרכים:

  • · בטרמינל, עם הפקודה /plugin
  • · בלשונית Code, דרך האפשרות Plugins בתפריט הצדדי
  • · או פשוט לבקש מ-Claude Code
> /plugin · ~/.claude/plugins/

הצ׳אט

Claude Desktop · claude.ai

ה-Plugin נשמר בחשבון שלנו, ולא במחשב. מתקינים אותו דרך Plugins בתפריט הצדדי.

NewSearchArtifactsPluginsMore
Claude Desktop · claude.ai

חשוב לדעת: גם ללשונית Code וגם לצ׳אט יש בתפריט הצדדי פריט בשם Plugins. מה שמתקינים בלשונית Code נשמר במחשב, ומה שמתקינים בצ׳אט נשמר בחשבון. בשקף הבא נראה מה עובר מאחד לשני.

מה עובר מהצ׳אט ל-Claude Code?

Plugin שהוספנו בצ׳אט נשמר בחשבון Claude שלנו. Claude Code שמחובר לאותו חשבון מוריד אותו לבד.

1

מתי זה עובד?

כש-Claude Code מחובר לחשבון Claude שלנו, באחת התוכניות בתשלום. אם נכנסנו עם מפתח API, זה לא עובד.

2

איך מזהים אותו?

במקום שם החנות כתוב synced. כדי להסיר אותו, מכבים אותו בצ׳אט.

3

ובכיוון ההפוך?

לא. מה שהתקנו ב-Claude Code נשאר בתיקייה במחשב ולא עולה לחשבון, ולכן הצ׳אט לא רואה אותו.

שני קבצי JSON

זה כל מה שצריך לכתוב. השם של ה-Plugin חייב להיות זהה בשני הקבצים.

.claude-plugin/marketplace.jsonjson
{
  "name": "my-ai-toolkit",
  "owner": { "name": "Our Name" },
  "plugins": [
    {
      "name": "everyday",
      "source": "./plugins/everyday",
      "description": "Email replies and news digests"
    }
  ]
}

נבחר ל-Marketplace שם ייחודי משלנו, למשל עם השם שלנו בתחילתו.

plugins/everyday/.claude-plugin/plugin.jsonjson
{
  "name": "everyday",
  "description": "Email replies and news digests",
  "author": { "name": "Our Name" }
}

לא נכתוב version: כך כל push חדש ל-GitHub נחשב גרסה חדשה, ולא צריך לזכור לעדכן מספר.
