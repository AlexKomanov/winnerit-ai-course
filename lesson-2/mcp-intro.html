מה זה MCP?

MCP — Model Context Protocol — הוא תקן פתוח שקובע איך אפליקציית AI מדברת עם כלים חיצוניים: דפדפן, GitHub, Notion, Jira ועוד.

כל כלי שמדבר MCP מתחבר לכל אפליקציה שמדברת MCP — בלי חיבור מיוחד לכל זוג.

כמו USB-C: פעם היה מטען אחר לכל מכשיר. היום יש חיבור אחד שכולם מכירים.

בלי MCP ועם MCP

נניח שמצאנו באג באתר ורוצים לפתוח עליו כרטיס.

בלי MCP

צילום מסך ← מדביקים לצ׳אט ← מעתיקים את התיאור ← פותחים Jira ← מדביקים ← מוסיפים קישור.
אנחנו הגשר בין ה-AI לכלים. הרבה העתק-הדבק.

עם MCP

"תבדוק את דף ה-checkout, ואם יש באג — תפתח עליו כרטיס ב-Jira עם צעדים לשחזור."
Claude פותח את הדפדפן, בודק, וכותב את הכרטיס בעצמו. אנחנו רק מאשרים.

שלושה חלקים

Host

האפליקציה שאנחנו עובדים בה: Claude Code או Claude Desktop. היא מחליטה מתי להשתמש בכלי.

Client

רכיב בתוך ה-Host שמחזיק חיבור לשרת אחד. לכל server יש client משלו.

Server

תוכנה קטנה שחושפת את היכולות של כלי אחד — למשל דפדפן או GitHub.

Server מקומירץ במחשב שלנו, בדרך כלל עם npx
Server מרוחקכתובת URL באינטרנט, לרוב עם התחברות לחשבון
פרוטוקול אחדClaude לא צריך לדעת איך כל כלי בנוי מבפנים

מה server נותן?

כל server יכול לחשוף שלושה סוגים של יכולות.

Tools

actions

פעולות ש-Claude יכול להפעיל בשבילנו.

למשל: לפתוח דף ולמלא טופס (Playwright), לפתוח issue (GitHub), ליצור דף (Notion).

Resources

data

מידע ש-Claude יכול לקרוא ישר מהמקור, בלי העתק-הדבק.

למשל: תוכן קובץ, רשומה ממסד נתונים, כרטיס Jira עם כל ההיסטוריה.

Prompts

templates

תבניות מוכנות שה-server מגדיר לשימוש חוזר.

למשל: "סכם את ה-pull requests הפתוחים".

מחברים server ל-Claude Code

פקודה אחת בטרמינל. ה--- מפריד בין ההגדרות של Claude לבין הפקודה שמריצה את ה-server.

1local

Server מקומי

רץ במחשב שלנו. כאן — דפדפן אמיתי ש-Claude שולט בו:

>_claude mcp add playwright -- npx @playwright/mcp@latest
2remote

Server מרוחק

כתובת באינטרנט. אחרי ההוספה נריץ /mcp בתוך Claude Code ונתחבר לחשבון.

>_claude mcp add --transport http notion https://mcp.notion.com/mcp
3check

בודקים

הרשימה מראה לכל server אם הוא מחובר, נכשל או מחכה להתחברות. בתוך Claude Code: /mcp.

>_claude mcp list

ברירת המחדל: ה-server זמין רק בפרויקט הנוכחי. כדי שיהיה בכל הפרויקטים — נוסיף --scope user.

שלוש דרכים לקבל MCP

פקודה

claude mcp add

מוסיפים server בעצמנו, כמו בשקף הקודם.

מתי: יודעים בדיוק איזה server רוצים.

Plugin

.mcp.json

Plugin יכול לארוז server בתוכו. מתקינים את ה-Plugin — וה-server מגיע איתו.

למשל: playwright@claude-plugins-official

Claude Desktop

connectors

גם Claude Desktop הוא Host. מחברים שם servers דרך ההגדרות — נעשה את זה במצגת הבאה.

מתי: רוצים MCP בלי טרמינל.

mcp.notion.com/mcp
