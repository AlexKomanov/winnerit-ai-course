Gems נמחקים

לפני התאריך הזה כדאי להוריד קבצים מה-Gems — חלק מהקבצים לא עוברים.

חשבונות עבודה ולימודים עוברים רק ב-2027. Canvas ו-Deep Research עדיין לא עובדים בתוך Skill.

אותו רעיון

Skill ב-Gemini בנוי בדיוק מאותם חלקים כמו SKILL.md שכתבנו.

name

my-skill-name

אותיות קטנות ומקפים, כמו email-reply. הטופס מתקן את הפורמט לבד.

description

use when…

משפט או שניים: מה ה-Skill עושה ומתי להשתמש בו. Google ממליצה להתחיל ב-"Use when".

instructions + files

the recipe

ההוראות עצמן, ואם צריך — קבצי ידע: מסמכים, טבלאות, תבניות.

הבונוס: Gemini יודע להעלות קובץ SKILL.md — כך שה-Skill שכתבנו ל-Claude Code עובד גם כאן, בלי לכתוב מחדש.

שלוש דרכים ליצור

כולן מתחילות באותו מקום: Customize ← Skills ← Create.

Create with Gemini

chat

מתארים בצ׳אט מה אנחנו צריכים, ו-Gemini שואל שאלות ובונה את ה-Skill איתנו.

מתי: עוד לא בטוחים איך לנסח את ההוראות.

Create manually

form

טופס ריק: שם, תיאור, הוראות וקבצים. אנחנו כותבים הכל.

מתי: יודעים בדיוק מה ה-Skill צריך לעשות.

Upload

SKILL.md

מעלים קובץ SKILL.md, או תיקייה שיש בה SKILL.md, או קובץ zip שלה.

מתי: כבר יש לנו Skill מ-Claude Code.

Skill ידני, צעד אחר צעד

1open

פותחים את Skills

נכנסים ל-gemini.google.com, לוחצים Customize בתפריט הצד (אם לא רואים — קודם More), ולמעלה בוחרים Skills.

Customize → Skills
2write

ממלאים את הטופס

לוחצים Create ← Create manually, ומזינים שם, description והוראות — בדיוק כמו ב-SKILL.md.

Create → Create manually
3save

קבצים ושמירה

אם צריך ידע — Add ומעלים קבצים מהמחשב או מ-Google Drive. בסוף לוחצים Create למעלה.

Add → files / Drive → Create

מה צריך: חשבון Google אישי וגיל 18 ומעלה. קבצים מ-Drive דורשים גם Keep Activity מופעל.

קבצי ידע

קבצים הופכים Skill כללי ל-Skill שמכיר את העולם שלנו: הנהלים, התבניות, המוצר.

אפשר להעלות

supported

PDF, DOCX, TXT, MD, CSV, XLSX, PPTX, תמונות, וקבצי טקסט וקוד נפוצים.

עד 100MB לכל הקבצים יחד.

מ-Google Drive

live link

קובץ מ-Drive נשאר מחובר למקור — כשנעדכן את המסמך, ה-Skill יקרא את הגרסה החדשה.

טוב ל: מסמך דרישות שמשתנה כל הזמן.

לא נתמך

not supported

פורמטים ישנים של Office (.doc, .xls, .ppt), קבצי zip, אודיו ווידאו.

פתרון: שומרים מחדש כ-DOCX / XLSX / PDF.

משתמשים ב-Skill

בחירה ידנית

בצ׳אט מקלידים / ובוחרים את ה-Skill מהרשימה. בחלק מהחשבונות הקיצור כבר התחלף ל-@.

הפעלה אוטומטית

אם ה-Skill פעיל, Gemini בוחר בו לבד כשהבקשה מתאימה ל-description.

כמה יחד

אפשר לשלב כמה Skills באותה שיחה, למשל מחקר ואחריו כתיבת מייל.

עד 100 פעיליםSkills פעילים בבת אחת
כיבוי זמניMore ← Deactivate. ה-Skill נשמר, רק לא מופעל לבד
אפליקציות מחוברותSkills עובדים גם עם האפליקציות של Google שחיברנו ל-Gemini

הדגמה

SKILL.md אחד, שני כלים

1upload

מעלים

ב-Skills לוחצים Create ← Upload, ובוחרים את SKILL.md מתוך ~/.claude/skills/email-reply/. ב-Mac, Cmd+Shift+. מציג תיקיות מוסתרות.

Create → Upload → SKILL.md → Open
2create

שומרים

Gemini קורא את השם, ה-description וההוראות מהקובץ. בודקים שהכל נכון ולוחצים Create.

3try

מנסים

בצ׳אט חדש מקלידים /, בוחרים email-reply ומדביקים מייל. אחר כך מנסים בלי לבחור — "תענה למייל הזה".

/ → email-reply → paste email

ניהול Skills

עריכה

edit

פותחים את ה-Skill, משנים description או הוראות ולוחצים Save. אפשר גם Edit with Gemini.

הורדה

download
