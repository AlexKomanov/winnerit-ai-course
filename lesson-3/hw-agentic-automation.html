Linear + Playwright

1linear account

יוצרים חשבון Linear

נרשמים ב-linear.app ומגדירים workspace חדש. התוכנית החינמית מספיקה לתרגיל: עד 250 issues ושני teams.

linear.app → Sign up → Create workspace
2linear mcp

Linear MCP ב-Claude Code

נחבר את Linear ל-Claude Code דרך ה-MCP. כך יוכל Claude Code לנהל טיקטים, לעדכן סטטוסים ולפתוח באגים — הכל ישירות מהצ'אט.

›claude mcp add --transport http linear https://mcp.linear.app/mcp
3playwright mcp

Playwright MCP ב-Claude Code

נחבר את Playwright ל-Claude Code דרך ה-MCP. כך יוכל Claude Code להפעיל דפדפן, לנווט בין דפים ולהריץ בדיקות על האפליקציה שלנו.

›claude mcp add playwright -- npx @playwright/mcp@latest

מוסיפים לתיקיית הפרויקט את ה-PRD שיצרנו עם Playwright MCP ו-Claude Desktop — קובץ ה-docx שמתאר את האפליקציה. זהו ה"תקציר" שינחה את כל הבדיקות שניצור.

פרויקט QA וטיקטים

1qa project

פרויקט חדש ב-Linear

מבקשים מ-Claude Code ליצור פרויקט חדש ב-Linear לניהול כל העבודה — פיצ'רים חדשים, שיפורים ובדיקות QA.

› Create a new Linear project called "[App Name]" for tracking features, improvements and QA tickets
2create tickets

טיקטים מה-PRD

מבקשים מ-Claude Code לקרוא את PRD.docx וליצור טיקטים של צוות QA לכל פיצ'ר — כל טיקט יכלול תרחישי בדיקה מפורטים, שלבים ממוספרים וקריטריוני הצלחה.

› Read PRD.docx and create QA tickets in Linear for every feature and user flow. Each ticket must include: a clear title, a step-by-step test scenario (numbered), expected result for each step, edge cases to cover, and acceptance criteria. Set all tickets to Todo status and label them "qa"

בדיקה וכיוונון

1review

סקירת הטיקטים ב-Linear

נפתח את פרויקט ה-QA ב-Linear ונעבור על כל הטיקטים שנוצרו. נבדוק שלבי בדיקה, קריטריוני הצלחה ותיעדוף.

Linear → [App Name] → All Issues → review each ticket
2correct

עדכון ותיקון

אם טיקט לא מדויק — נכתוב ל-Claude Code מה לשנות. אפשר לתקן כותרת, להוסיף שלבים, לפרט edge cases או לשנות priority.

› Update the QA ticket for [feature]: revise the test steps to include [scenario], add edge cases for empty state, and set priority to High

ביצוע ומעקב

1what we ask

מה נבקש מ-Claude Code

בשיחה אחת נבקש לעבור על כל טיקטי ה-QA ב-Linear, לבצע כל תרחיש עם Playwright MCP שלב-שלב, לעדכן סטטוסים בזמן אמת — ולפתוח טיקטי באג מפורטים לכל תרחיש שנכשל.

2prompt

הפרומפט

בקשה אחת מפורטת שמכסה ביצוע, עדכון סטטוסים ופתיחת באגים — הכל בפעולה אחת.

› Go through each QA ticket in the Linear project one by one. For each ticket: execute the test scenario step by step using Playwright MCP, verify the expected result at each step, then update the ticket status — mark "Done" if all steps pass, or keep it open if anything fails. For each failed scenario, create a Bug ticket in Linear with label "bug", describe the failing step, the expected vs actual behavior, and link it to the original QA ticket
