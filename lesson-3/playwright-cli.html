מה זה Playwright CLI?

כלי של Microsoft שנותן לסוכן קוד, כמו Claude Code, לשלוט בדפדפן אמיתי — בפקודות קצרות בטרמינל.

כל פעולה היא פקודה אחת: לפתוח דף, להקליד, ללחוץ, לצלם מסך.

כמו שלט רחוק לדפדפן. כל כפתור בשלט עושה דבר אחד, ו-Claude לוחץ על הכפתורים בשבילנו.
terminal
$ playwright-cli open https://demo.playwright.dev/todomvc/ $ playwright-cli type "Buy groceries" $ playwright-cli press Enter $ playwright-cli check e21 $ playwright-cli screenshot

כמה מקום זה תופס?

ל-Claude יש שולחן עבודה מוגבל: חלון ה-context. כל מה שנכנס אליו תופס מקום שיכול היה לשמש לקוד ולבדיקות שלנו.

playwright mcp

מה חוזר ל-Claude?

אחרי כל פקודה חוזרות כמה שורות בלבד: כתובת הדף, הכותרת שלו, וקישור לקובץ snapshot.

ה-snapshot מתאר את כל מה שיש בדף: כפתורים, שדות, טקסטים. הוא נשמר בתיקייה .playwright-cli ולא נדחף לשיחה.

כמו קבלה עם מספר הזמנה. מקבלים פתק קטן, ואת כל הפרטים פותחים רק אם צריך.
terminal
> playwright-cli goto https://example.com ### Page - Page URL: https://example.com/ - Page Title: Example Domain ### Snapshot [Snapshot](.playwright-cli/page-…-679Z.yml)

איך Claude יודע על מה ללחוץ?

ב-snapshot כל רכיב בדף מקבל מספר קצר, שנקרא ref. במקום לתאר את הרכיב במילים, Claude משתמש במספר שלו.

כמו מספרים בתפריט. מזמינים "מנה 15" במקום לתאר אותה.

התקנה בשלושה צעדים

נדרש Node.js 20+ וסוכן קוד, כמו Claude Code.

1install

מתקינים את הכלי

התקנה אחת לכל המחשב. אחריה הפקודה playwright-cli זמינה בכל תיקייה.

>_npm install -g @playwright/cli@latest
2skills

מתקינים את ה-Skills

נריץ בתיקיית הפרויקט. ה-Skills מלמדים את Claude Code איך להשתמש בפקודות.

>_playwright-cli install --skills
3verify

בודקים שזה עובד

אם מופיעה רשימת הפקודות — הכלי מותקן ומוכן.

>_playwright-cli --help

בדיקה ראשונה

1open

פותחים Claude Code

נפתח אותו בתיקיית הפרויקט, שבה התקנו את ה-Skills.

>_claude
2ask

מבקשים בשפה רגילה

נכתוב מה לבדוק. Claude יבחר את הפקודות בעצמו.

Use playwright skills to test https://demo.playwright.dev/todomvc/. Take screenshots for all successful and failing scenarios.
claude code
> Use playwright skills to test …/todomvc/ ● Bash(playwright-cli open …/todomvc/) ● Bash(playwright-cli type "Buy groceries") ● Bash(playwright-cli press Enter) ● Bash(playwright-cli screenshot) ✓ Todo added. Screenshot saved.

איך רואים מה קורה?

כברירת מחדל הדפדפן רץ ברקע, בלי חלון. יש שלוש דרכים לראות אותו.

1headed

דפדפן עם חלון

נוסיף --headed לפקודת הפתיחה, והדפדפן ייפתח מול העיניים.

>_playwright-cli open https://playwright.dev --headed
2dashboard

לוח בקרה

חלון אחד שמציג את כל הדפדפנים הפתוחים, ומאפשר גם לשלוט בהם.

>_playwright-cli show
3screenshot

צילום מסך

נבקש מ-Claude לצלם בכל שלב חשוב, ונקבל קובץ תמונה שאפשר לפתוח.

>_playwright-cli screenshot

CLI או MCP?

שניהם שולטים באותו דפדפן. נבחר לפי המקום שבו Claude עובד, ולפי מה שחשוב לנו יותר.

playwright cli
