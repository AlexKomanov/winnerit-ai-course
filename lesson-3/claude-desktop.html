מה זה Claude Desktop?

אפליקציה מקומית ל-Mac + Windows (ול-Linux בגרסת beta) — לא עוד טאב בדפדפן. גישה ישירה לקבצים, שיחה אחת לכל סוגי העבודה, וספרייה של Connectors.

היתרון הגדול: Claude יכול לגשת למחשב שלנו, לקרוא קבצים, ולפעול אוטונומית — בלי שנצטרך להדביק לצ'אט.

claude.com/download · mac · windows

איך עובדים באפליקציה?

פעם בחרנו בין Chat ל-Cowork. מאז ספטמבר 2026 הם שיחה אחת, ורק Code נשאר בלשונית נפרדת.

שאלה מהירה

שואלים ומקבלים תשובה, כמו ב-claude.ai. באותה שיחה אפשר להמשיך למשימה גדולה יותר.

משימה שלמה

מתארים את התוצאה, נותנים ל-Claude גישה לתיקייה, והוא עובד לבד על הקבצים. לא בוחרים מצב מראש.

Code

לשונית נפרדת בראש סרגל הצד: Claude Code, עם ממשק של אפליקציית Desktop.

עדיין רואים Chat ו-Cowork בתיבת ההודעה? העדכון מגיע לחשבונות בהדרגה. הכל עובד אותו דבר, רק בוחרים Cowork לפני משימה שלמה. כמה Claude עובד לבד קובעים בתיבת ההודעה: Auto / Manual.

יכולות AI בלבד — הוראות לסגנון, תפקיד או תחום. אין חיבור לשירות חיצוני.

חיבור לשירות חיצוני דרך MCP — Claude מקבל רשימת פעולות מוכנות לאותו שירות. לדוגמה: Notion, Linear, Gmail.

Plugins

חבילה אחת להתקנה, שיכולה להכיל Skills, Connectors, פקודות ו-agents — הכל בבת אחת.

MCP · Connector · Plugin

MCP

הפרוטוקול שמאחורי הקלעים. server שלא מופיע בספרייה נוסיף בעצמנו: עם כתובת URL, או כקובץ Extension שמותקן במחשב.

Connector

דרך קלה יותר להוסיף MCP server מתוך ממשק Claude Desktop. עדיין יכול להידרש אימות בחלק מהשרתים — אבל ללא עריכת קבצי הגדרות.

Plugin

חבילה מוכנה להתקנה: Skills, Connectors, פקודות ו-agents שנבנו לעבוד יחד סביב אותו שירות או אותה משימה.
